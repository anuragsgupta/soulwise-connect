  Call 1: 20251124-162900-330n8e  ← User message

🟢 NEW TIMESTAMP GENERATION:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Format: YYYYMMDD-HHmmss-milliseconds+counter(3)+random(3)

Sequential counter resets each millisecond:

  Millisecond 330:
    Call 1: 20251124-162900-330000abc  ← counter=0
    Call 2: 20251124-162900-330001def  ← counter=1
    Call 3: 20251124-162900-330002ghi  ← counter=2

  Millisecond 331:
    Call 1: 20251124-162900-331000jkl  ← counter resets to 0

Uniqueness: counter (1000) × random (46,656) = 46,656,000 combinations per ms
            = GUARANTEED uniqueness for up to 1000 calls/millisecond
